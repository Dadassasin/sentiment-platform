# Лаборатория анализа тональности

Десктопная платформа для локального анализа и мониторинга тональности в русскоязычных текстовых данных. Текущая версия реализует MVP без активного обучения.

## Возможности

- загрузка данных из CSV, TXT, Excel;
- выбор текстовой колонки;
- опциональная предобработка: нижний регистр, очистка пунктуации, стоп-слова, лемматизация через `pymorphy3`;
- transformer-анализ тональности через локально загруженные модели Hugging Face;
- таблица результатов с вероятностями классов;
- карточки метрик, распределение классов, распределение уверенности;
- простой мониторинг дрейфа по батчам вероятностей;
- сравнение модельных профилей;
- экспорт HTML-отчета.

Активное обучение пока не включено по заданию. Пакет `app/active_learning` оставлен как точка расширения.

В приложении нет лексиконных, rule-based или других простых эвристических методов анализа тональности. Если transformer-модель не загружена локально или не подходит для sequence classification, анализ не запускается и показывает ошибку.

Предобработка по умолчанию выключена, чтобы transformer-модель получала сырой текст в том виде, на котором обычно обучаются RuBERT/RoBERTa-классификаторы.

## Запуск

```bash
python -m app.main
```

Если окружение еще не установлено:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```

## Формат данных

CSV и Excel должны содержать колонку с текстом. Приложение автоматически предпочитает имена `text`, `текст`, `review`, `content`, `message`, но колонку можно выбрать вручную.

Опциональная колонка источника: `source`, `источник`, `platform`, `site`.

TXT-файл читается как один текст на строку.

## Transformer-модели

По умолчанию приложение загружает модели только из локального пути или локального кэша Hugging Face. Это сохраняет инференс локальным и не использует Cloud API.

Кэш Hugging Face по умолчанию направлен в `models/huggingface` внутри проекта.

В поле "Модель" можно выбрать профиль из списка или вписать локальный путь к fine-tuned модели, например:

```text
models/rubert-tiny2-sentiment
```

Обычные базовые модели вроде `cointegrated/rubert-tiny2` или `DeepPavlov/rubert-base-cased` нужно сначала дообучить как `AutoModelForSequenceClassification`; иначе они не используются для sentiment-инференса.

Если нужно разрешить разовую загрузку весов через `transformers`, перед запуском можно установить переменную:

```bash
set SENTIMENT_ALLOW_MODEL_DOWNLOAD=1
python -m app.main
```

После загрузки модель будет использоваться локально.

## Ограничения текущей версии

- требуется локально доступная transformer-модель для классификации тональности;
- Accuracy/F1 показываются только на вкладке профилей моделей как справочные показатели;
- PDF-экспорт, SHAP/LIME и fine-tuning трансформеров оставлены для следующих итераций.
