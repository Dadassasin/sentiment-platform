# Sentiment Platform

Десктопная платформа для анализа тональности текста на Python и PyQt6.

Проект предназначен для лабораторной работы по сопровождению программных систем: загрузка датасетов, анализ текста transformer-моделью, обучение собственной модели, мониторинг результатов и формирование HTML-отчета.

## Возможности

- загрузка CSV, TXT и Excel-файлов;
- пакетный анализ тональности текстов;
- быстрая проверка одного текста;
- настройка предобработки русского текста;
- обучение transformer-классификатора на пользовательских метках;
- сравнение нескольких локальных моделей;
- простой активный отбор неуверенных примеров для ручной разметки;
- мониторинг результата анализа: уверенность, перекос классов, предупреждения и сравнение с предыдущим запуском;
- экспорт HTML-отчета.

## Требования

Рекомендуется Python `3.10-3.13`.

Python `3.14` не рекомендуется, потому что для него могут отсутствовать PyTorch CUDA wheels.

## Установка

Создать виртуальное окружение:

```powershell
python -m venv venv
```

Активировать окружение в PowerShell:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\venv\Scripts\Activate.ps1
```

Установить зависимости:

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Скачать NLTK stopwords:

```powershell
python -m nltk.downloader stopwords
```

## Запуск

```powershell
python -m app.main
```

## CUDA

В `requirements.txt` указан PyTorch CUDA `cu121` для Windows и Linux:

```text
torch==2.5.1+cu121
```

Проверить доступность GPU:

```powershell
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"
```

Ожидаемый результат для CUDA-сборки:

```text
2.5.1+cu121
True
```

## Основные разделы приложения

- **Данные** - загрузка train, validation и test датасетов.
- **Анализ** - пакетный анализ файла или быстрая проверка одного текста.
- **Обучение** - настройка эксперимента и дообучение модели.
- **Модели** - просмотр локальных моделей и их меток.
- **Сравнение** - сравнение поведения нескольких моделей.
- **Мониторинг** - контроль стабильности результата анализа.
- **Отчеты** - предпросмотр и экспорт HTML-отчета.

## Мониторинг

Мониторинг не повторяет таблицу анализа. Он показывает контрольные признаки:

- индекс необходимости проверки `0-100`;
- статус контроля;
- предупреждения по порогам;
- среднюю уверенность;
- изменение уверенности по батчам;
- долю сомнительных ответов;
- доминирующий класс;
- сравнение с предыдущим запуском.

Снимок предыдущего запуска сохраняется в:

```text
reports/monitoring_last_run.json
```

Файл добавлен в `.gitignore`.

## Активное обучение

Модуль `app.active_learning` выбирает тексты с низкой уверенностью модели.

Если максимальная вероятность предсказания ниже порога, пример считается кандидатом для ручной разметки.

```python
from app.active_learning import select_uncertain_examples

items = select_uncertain_examples(texts, probabilities, threshold=0.6)
```

## HTML-отчет

HTML-отчет содержит:

- общую сводку анализа;
- распределение классов;
- распределение уверенности;
- раздел мониторинга результата;
- примеры с низкой уверенностью;
- первые 500 результатов анализа.

## Примечания

- Папки `venv/`, `models/`, `reports/preview_report.html` и временные артефакты игнорируются Git.
- Для transformer-моделей агрессивную предобработку обычно лучше оставлять выключенной, если модель обучалась на сыром тексте.
